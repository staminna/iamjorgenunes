SaaS solution that automatically measures carbon captured by forests in a cheap, fast and reliable way — rewarding landowners for protection.

### Highlights

- **200+ containerised API endpoints** with high-volume satellite-imagery ingestion.
- **IaC**: Terraform for multi-environment, cloud-agnostic deployments; Ansible for configuration and rollout.
- **AWS native**: IAM, EC2, S3, RDS, SES, ECS with GitHub Actions CI/CD and automated testing.
- **Computer vision** models for forest carbon scoring (Torch, torchvision, Pillow, scipy).
- **Geospatial**: PostgreSQL + PostGIS, MongoDB, Redis and ETL pipelines.
- **Bureau Veritas audit**: scientific certification with **3.5M ROI**; Three.js digital twin between client forests and the production engine.
- **ESA collaboration**: Python microservices for European Space Agency feeds.
