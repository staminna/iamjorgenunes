Recording-studio platform built on **Directus 12 + Next.js** — booking and content management for a studio in Aveiro, delivered remotely. The project received a **Directus Innovation Grant**.

### Highlights

- **Booking platform**: multilingual Directus 12 + Next.js site with a studios catalogue, artist showcase and lead capture; embedded self-hosted scheduling with graceful fallback and e-mail confirmations.
- **Directus extensions**: per-user mailboxes built as extensions, and an agent-driven research pipeline writing verified leads into Directus.
- **MCP for AI agents**: published the Directus MCP server (**29+ tools**, 97%+ test coverage) so AI agents can query and act on the backend.
- **Backend & delivery**: Node.js / TypeScript services, PostgreSQL and Redis; Auth0 (OAuth2 / OIDC, RBAC); Docker Compose parity across environments; unit, integration and e2e suites.
- **Infrastructure**: Hetzner Linux server with git-driven deploys and systemd.

Stack: Directus 12, Next.js, React, Node.js, TypeScript, PostgreSQL, Redis, Auth0, Docker Compose, Hetzner, systemd.
