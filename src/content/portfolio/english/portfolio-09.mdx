Friends and events platform built on a **Go backend with PostgreSQL / PostGIS**, with Flutter clients on iOS, Android and Web, running in Docker on Hetzner.

### Highlights

- **Aggregation API**: seven event sources normalised into one JSON / GeoJSON API at `api.after.zone` — **58,000+ events across 3,100+ cities** — with TTL stale-while-revalidate caching and a public health endpoint.
- **Delivery**: test-gated `linux/amd64` Docker image builds and deploys.
- **Operations console**: Next.js dashboards covering every pull from the event APIs, plus an MCP tool so AI agents monitor ingestion.
- **Privacy by design**: a WebSocket hub where live location is held in memory only and never persisted.

Stack: Go, PostgreSQL / PostGIS, Flutter, Next.js, WebSocket, Docker, Hetzner.
