I have built delivery pipelines at the European Commission (Jenkins and GitHub Actions with automated builds and Jest testing, through several platform migrations), inside the European Central Bank's GitLab and JIRA release flow, and for every platform I run today. The pipeline is not just the YAML: it is the test gate that stops a bad build, the deploy user that cannot do more than deploy, and the runbook someone else can follow at 3am.

## What I deliver

- **Test-gated builds** — unit, integration and e2e suites that block a release, with enforced coverage gates (my `directus-mcp-server` sits above 97%).
- **GitHub Actions, GitLab, Jenkins** — whichever you already run, wired for fast feedback and reproducible artefacts.
- **Least-privilege deploys** — non-root deploy users, fast-forward-only merges, API token rotation.
- **Release management** — runbooks and release plans; at Keyprog I was sole coordinator across six external parties, including App Store and Play Store compliance.
- **Production migrations** — build and packaging scripts, staged rollouts and a tested way back.
