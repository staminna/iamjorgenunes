I am a platform engineer who also ships the services on top, which means the infrastructure is designed by someone who knows what runs on it. api.after.zone is a Go backend aggregating seven event sources into one JSON / GeoJSON API — 58,000+ events across 3,100+ cities — with TTL stale-while-revalidate caching and a public health endpoint. Keyprog is a production Directus backend with 9,600+ SKUs, 29,000+ images, five languages, 200+ collections, 100+ API endpoints and 50+ automation flows.

## What I deliver

- **APIs built to be operated** — health endpoints, structured logging, caching with explicit invalidation, graceful shutdown.
- **Correctness under concurrency** — idempotent ERP invoicing, atomic reservations so concurrent supplier events can't double-order, explicit locking where it counts.
- **Data modelling that holds** — PostgreSQL / PostGIS and Redis schemas that survive integrations instead of being rewritten around them.
- **Directus as a production backend** — data models, roles, policies, ACLs, Flows, hooks and extensions, running real e-commerce and booking platforms.
- **Tested end to end** — unit, integration and e2e suites wired into the pipeline that gates the deploy.
