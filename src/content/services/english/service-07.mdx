I build the tooling I use. `cicd-mcp-pipeline` on npm gives AI assistants unified control over Docker (local and SSH-remote) and Kubernetes (Kustomize, Gateway API with Gloo / Envoy) across local, staging and production, with environment diffing, health checks, API token rotation and pre-deployment CI/CD validation. `@staminna/directus-mcp-server` runs on a least-privilege service token behind enforced CI coverage gates above 97%. On Exponent, AI agents run infrastructure operations through MCP with a LangGraph agent checkpointed in PostgreSQL.

## What I deliver

- **MCP servers for real operations** — Docker, SSH and Kubernetes deployment control, exposed as tools an agent can use safely.
- **Agents with state that survives** — LangGraph orchestration checkpointed in PostgreSQL rather than held in memory.
- **Governance built in** — audit trails aligned with ISO/IEC 42001, least-privilege service tokens, and human review before anything lands.
- **Monitored ingestion** — an MCP tool so agents watch every pull from the event APIs feeding after.zone, with a Next.js ops console in front.
- **Automation at volume** — 200+ workflows at Co2Offset.ai covering CI/CD, ETL and event-driven ingestion of satellite and ground data.
